# Cloud-Native Portfolio & DevOps Platform

A production-style personal portfolio project built to demonstrate
Cloud, DevOps, DevSecOps and infrastructure automation skills.

## Technologies

- Linux
- Git & GitHub
- Docker
- AWS
- Terraform
- Kubernetes
- GitHub Actions
- Prometheus
- Grafana
- DevSecOps

## Project Goals

- Build a personal portfolio application
- Containerize the application using Docker
- Deploy the application to AWS
- Provision infrastructure using Terraform
- Orchestrate containers using Kubernetes
- Implement CI/CD using GitHub Actions
- Add security scanning
- Implement monitoring and logging
